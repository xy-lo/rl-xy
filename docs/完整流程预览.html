输入5.000host 将 prompt [1,2] 送入 D0，再通过 P2P 复制到 D1。
生成14564.530A/B 各 prefill 两 token，随后 A1/B1 decode、释放 B KV，再 decode A2、释放 A KV。D1 logits 发给 D0，由 D0 采样并广播 token。
奖励19.000已完成回答送回 host；固定规则奖励 A=1、B=0，并向 D1 发送奖励结果和阶段围栏。
Reference 概率13735.545冻结 Reference 对 A/B 的 teacher-forcing 输入执行前向，取 3/2 个回答位置的 log-prob。
旧策略概率13735.545更新前 actor v0 对同一 A/B 输入执行无梯度前向，输出 old log-prob。
组内优势10.000组均值为0.5，A/B 优势为+0.5/-0.5；D0 将结果复制给 D1。
训练 A26254.590先清零本轮 FP32 梯度缓冲；执行 A 的前向、全局分母5的损失、损失到 logits 的反向、模型反向及梯度累积。
训练 B19005.060执行 B 的同类前后向并累积到同一梯度缓冲；B 不会再次清零。
梯度裁剪3234.500分片贡献局部平方和；复制 norm 参数由 owner 贡献；标量 AllReduce 后应用裁剪。
优化器9696.000shape-only AdamW 读取 gradient/master/m/v，写 master/m/v/actor；Reference 不写。
发布3.500全分片小 payload AllReduce 围栏后发布 actor v1；publish marker 显式为1 ns。
回收1.000记录本轮临时 KV 已释放；cleanup marker 显式为1 ns；下一轮从新 actor 版本继续。

结果口径

这是操作级 synthetic fixture，未做硬件校准或数值训练。16352 B/die 是常驻状态+KV 的已跟踪小计；主toy尚未展开activation tape、tile/SRAM与本地DMA，不能当作整轮真实内存峰值。详细边界及可复现命令见 Markdown 主文档。
